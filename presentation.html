What it is

AI that turns a photo into three clear outputs.

Map

Visible findings

Boxes show what the detector found and where.

Summarize

Activity overview

Counts create a neutral, non-diagnostic summary.

Guide

Personalized plan

The photo and user context shape practical guidance.

Technology

Two models. Two different jobs.

1

Browser

Resizes the image so both models analyze the same pixels.

2

Roboflow YOLO

Detects six classes and returns boxes, counts, and confidence.

3

Groq Vision

Combines the image, detections, and profile into readable guidance.

API keys stay server-side. Clarity Labs does not save the uploaded image.
